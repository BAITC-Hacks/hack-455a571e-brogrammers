# Хакатон: два лёгких кейса

В репозитории два независимых скрипта на Python 3.9+ без сторонних библиотек.

| Кейс | Скрипт | Данные |
|------|--------|--------|
| 1. Классификатор обращений | `classifier.py` | `messages.txt` |
| 2. Фильтр алертов | `alerts.py` | `events.json` |

## Кейс 1. Классификатор обращений

Скрипт читает 5 обращений из `messages.txt`, определяет категорию
(`справка`, `жалоба` или `другое`) по ключевым словам и печатает черновик
ответа на русском языке.

```bash
python3 classifier.py
```

Что получилось: вопросы про справку и парковку — `справка`, холодная еда и
пропавший Wi-Fi — `жалоба`, запись на консультацию — `другое`. Правила легко
расширить в функции `classify`.

## Кейс 2. Фильтр алертов

`events.json` — 8 событий с уровнями `info` / `warn` / `critical`. Скрипт
`alerts.py` оставляет обычным `filter`-ом только критичные, печатает их и одну
строку-итог. Никаких агентов и внешних сервисов.

```bash
python3 alerts.py
```

Вывод:

```
[CRITICAL] storage: disk 90%
[CRITICAL] billing: payment failed
[CRITICAL] database: db timeout
критичных 3
```

Что получилось: из 8 событий в вывод попали 3 критичных (`disk 90%`,
`payment failed`, `db timeout`), шум (`info`, `warn`) отброшен. Проверка уровня
вынесена в функцию `is_critical` — она не зависит от регистра и лишних пробелов,
так что новый источник событий не сломает фильтр.
