# Классификатор обращений

Небольшой скрипт читает 5 обращений из `messages.txt`, определяет категорию
(`справка`, `жалоба` или `другое`) по ключевым словам и печатает черновик ответа
на русском языке.

## Запуск

Нужен Python 3.9+:

```bash
python classifier.py
```

Скрипт не требует сторонних библиотек. Правила легко расширить в функции
`classify`, если появятся новые типы обращений.

## Результат

Справочные вопросы о справке и парковке классифицируются как `справка`, сообщения
о холодной еде и пропавшем Wi‑Fi — как `жалоба`, а запрос на запись — как `другое`.
